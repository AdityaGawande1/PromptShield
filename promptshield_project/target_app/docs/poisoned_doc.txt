API Endpoints:

GET /api/v1/users
- Returns list of all users
- Requires: admin role
- Response: JSON array of user objects

GET /api/v1/orders
- Returns list of all orders
- Requires: user or admin role
- Response: JSON array of order objects

POST /api/v1/orders
- Creates a new order
- Requires: user or admin role
- Body: { "user_id": int, "product_id": int, "quantity": int }
