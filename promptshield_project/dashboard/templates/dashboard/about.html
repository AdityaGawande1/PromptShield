What PromptShield Does

PromptShield is an automated security-testing framework for LLM and agent applications. It fires a curated set of adversarial prompts at a sample chatbot, applies a lightweight detection-and-blocking layer in front of it, logs every incident, and measures how effective that protection is using four evaluation metrics.

Built as an academic mini project — scoped as a red-teaming and detection prototype, not a production security product.

How It Works
  1. Target App — a WidgetCorp customer-support chatbot with a database query tool and a small document-retrieval (RAG) system.
  2. Detection Layer — regex/keyword rules, embedding-similarity matching against known attacks, and an optional LLM-judge call.
  3. Output Guard — scans the chatbot's response for leaked secrets, PII, or unsafe content before it reaches the user.
  4. Incident Log & Metrics — every request is logged, and results are compared with protection on vs. off.
